# MetalBid

Digital metal auction platform — built by AspiraSys for Metal Bid Technologies.

**🔗 Live demo:** https://manzoorilahi77.github.io/MetalBid/

## About

MetalBid is a digital auction platform for buying and selling metal/scrap lots, covering
the full lifecycle from entity and lot verification through live bidding to settlement and
logistics handover, across 6 roles (Buyer, Seller, Executive Admin, Sub Admin, Super Admin,
and Guest).
